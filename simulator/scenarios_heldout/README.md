# Held-out scenarios

The author writes scenarios 7 (ransomware-like change pattern) and 8 (Trident PVC burst) by
hand and puts them in this directory as `<scenario>.yaml`, using the same format as
`simulator/scenarios/`. They are never used in training.

Nothing here is generated by tooling. The engine and CLI already search this directory, so
once a file exists it runs with, for example:

    python -m simulator.run --scenario ransomware_like_change --variant severe --seed 1 --out out.duckdb

Scenario 8 uses the `trident_backend` object type, which the healthy cluster does not emit.
Declare the backend and its metrics in the file's `extra_objects` list.
