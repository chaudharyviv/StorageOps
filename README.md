# StorageOps Intelligence Platform

A NetApp-only, end-to-end AI system: simulated ONTAP telemetry, forecasting, an incident
summarizer, an evaluation and CI gate, an MCP server, a triage agent with an approval and
audit gate, and a drift-to-retrain loop.

**All data in this repository is synthetic.** No real customer data, credentials or tokens
are used or committed.

Status: scaffold only. See `docs/` and `CLAUDE.md` for the working rules.
